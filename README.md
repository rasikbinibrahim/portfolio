# Rasik Nizam's Professional Portfolio

A premium, enterprise-level portfolio built with React, TypeScript, and Framer Motion.

## 🚀 Getting Started

1. **Clone or Navigate to the project folder:**
   ```bash
   cd rasik-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React & React Icons
- **Typography:** Inter & Outfit (Google Fonts)

## ✨ Features

- 🌓 **Dark/Light Mode:** Seamless transition with persistent theme preference.
- 🧱 **Sectioned Architecture:** Hero, About, Skills, Experience, Projects, Achievements, and Contact.
- 📈 **Animated Skills:** Progress bars with scroll triggers.
- 🕒 **Timeline UI:** Professional vertical experience timeline.
- 📱 **Fully Responsive:** Optimized for Mobile, Tablet, and Desktop.
- 🎨 **Premium Design:** Glassmorphism, subtle gradients, and high-quality micro-interactions.

## 📁 Project Structure

- `src/context`: Theme state management.
- `src/components`: Reusable UI elements (Navbar, etc.).
- `src/sections`: Main page sections.
- `src/index.css`: Global styles and Tailwind configuration.
